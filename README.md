# Lora

Голосовой ИИ-ассистент для macOS и Windows. Скажите «Лора» — и она откроет приложение, поставит таймер, переключит трек, ответит на вопрос или надиктует текст в любое окно. Распознавание речи и активатор работают локально, без интернета.

## Скачать

Последняя версия — на странице [Releases](https://github.com/GRYurv/Lora-AI-Assistant/releases/latest).

| Система | Файл |
| --- | --- |
| macOS 14+, Apple Silicon (M1–M4) | `Lora_<версия>_aarch64.dmg` |
| macOS 14+, Intel | `Lora_<версия>_x64.dmg` |
| Windows 10/11 | `Lora_<версия>_x64-setup.exe` (или `.msi`) |

Обновления Lora находит и ставит сама: «Настройки → Обновления».

**macOS.** Сборка пока не подписана сертификатом Apple. При первом запуске macOS сообщит, что не может проверить разработчика: откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите «Всё равно открыть». Или в Терминале:

```sh
xattr -dr com.apple.quarantine /Applications/Lora.app
```

**Windows.** SmartScreen может показать предупреждение о неизвестном издателе: «Подробнее → Выполнить в любом случае».

При первом запуске Lora предложит выбрать и скачает модель распознавания речи; размер каждой модели показан на её карточке.

## Плагины

Lora расширяется плагинами на JavaScript, скомпилированными в WebAssembly. Каждая команда плагина работает и без ИИ (по фразам-триггерам), и с ИИ (как инструмент для модели).

- [Руководство разработчика](docs/plugins/README.md) — полное, на русском

- [`templates/plugin-js`](templates/plugin-js) — шаблон плагина
- [`plugins-examples/coin-flip`](plugins-examples/coin-flip) — готовый пример
